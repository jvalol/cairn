# Specs

What the game does, one file per area. `TEMPLATE.md` is the starting point for a
new one, and `CLAUDE.md` in the repo root describes the flow.

Specs are numbered in the order they were written. The number is an identifier,
not a priority, and it never changes once a spec exists.

| Spec | Covers |
| --- | --- |
| [0001](0001-the-cairn.md) | The tower, the pull, and when a run is over |
| [0002](0002-the-hand.md) | Holding a block rather than watching it leave |
| [0003](0003-what-wood-looks-like.md) | Grain, drawn rather than loaded |
| [0004](0004-the-sound-of-wood.md) | A note when a block hits something |
